About AgriVision AI

AgriVision AI is a college mini project that demonstrates an end-to-end applied machine learning workflow: dataset preparation, transfer learning with a lightweight CNN, model evaluation, and deployment behind a simple web interface.

How it works

  1. The user uploads a photo of a crop leaf.
  2. The image is preprocessed (resized, normalized) to match the model's training pipeline.
  3. A pretrained MobileNetV2-based convolutional neural network (fine-tuned on the PlantVillage dataset by its original author, loaded directly from the Hugging Face Hub) classifies the leaf — no training happens on this machine.
  4. The predicted class and confidence score are returned, along with structured information (cause, symptoms, prevention, cure) from a disease-information database.

Technology stack

  • Model: linkanjarad/mobilenet_v2_1.0_224-plant-disease-identification — a pretrained MobileNetV2 model (PyTorch, via Hugging Face transformers), used directly for inference
  • Backend: Flask (Python)
  • Frontend: HTML, CSS, vanilla JavaScript
  • Training data behind the pretrained model: PlantVillage / "New Plant Diseases Dataset" — the model author trained on this; this project does not re-download it or retrain

Limitations

This tool provides a preliminary AI-based identification only. It is trained on a limited set of crops and diseases, was not validated against real field conditions by agricultural experts, and should never replace professional diagnosis. Always confirm with a qualified agronomist or extension officer before acting on the result.
